
# MerchantAI – AI Sales Growth Copilot

## Problem Statement
Small merchants often have sales data but lack intelligent tools to understand why sales change and what actions could improve revenue.

## Key Features
- Sales dashboard
- Product performance analysis
- Customer analysis
- Sales forecasting
- AI business recommendations
- Low-performing product detection
- Natural-language business queries

## Tech Stack
- **Frontend:** Flutter
- **Backend:** FastAPI, Python
- **Database:** PostgreSQL
- **Data & Analytics:** Pandas, Scikit-learn
- **AI/LLM:** LLM APIs
